Everything

The Everything MCP server is a comprehensive reference/test server demonstrating all features of the Model Context Protocol. It provides a variety of tools, resources, and prompts to showcase MCP capabilities and is ideal for testing and development of MCP client applications.

"everything": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-everything" ] }

Fetch

The Fetch MCP server provides web content fetching and conversion capabilities. It enables LLM-based agents to retrieve and process content from web pages, automatically converting HTML to Markdown for easier consumption.

"fetch": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-fetch" ] }

Filesystem

The Filesystem MCP server offers secure file operations with configurable access controls. It is a Node.js implementation of the MCP that allows reading, writing, and manipulating files and directories through a standardized interface.

"filesystem": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-filesystem", "C:/" ] } 
"filesystem": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-filesystem", "C:/", "D:/" ] }

Memory

The Sequential Thinking MCP server facilitates structured, step-by-step problem solving. It breaks down complex problems into sequential thoughts, tracks the progression of the reasoning process, and can generate summaries of each stage.
